# Ferry

**在 Mac 上管理 Android 手机文件 · 插线即用，手机不用装软件**

用数据线连上手机，就能在 Mac 上导入照片、浏览和拷贝手机里的文件。手机上不用装任何 App（只用手机系统自带的“传输文件”功能）。

## 下载

到 [Releases](https://github.com/reatang/ferry-android-file-release/releases/latest) 下载最新的 `Ferry-<版本>.dmg`，打开后把 Ferry 拖进“应用程序”文件夹。

- 需要 macOS 14 或更新版本，支持 Apple 芯片和 Intel 的 Mac。
- **只从这个页面下载 Ferry。** 新版本也只在这里发布：App 里的“帮助 › 检查新版本…”会打开这个页面。别处转载的安装包可能被改过。

### 第一次打开

Ferry 还没有经过苹果的认证，第一次打开时 Mac 会提示“无法打开”或“无法验证开发者”。按下面的步骤放行一次，以后就能直接打开：

1. 点“完成”或“好”关掉提示。
2. 打开“系统设置 › 隐私与安全性”，滚到最下面，在“已阻止使用 Ferry”旁边点“仍要打开”，输入开机密码确认。

只对从本页下载的 Ferry 这样做；来源不明的 App 不要用这个办法强行打开。DMG 里的《打开前请看》也有同样的说明。

<details>
<summary>核对下载的文件（可选）</summary>

每个版本都附有 `.sha256` 文件。在“终端”里运行（把版本号换成你下载的）：

```bash
shasum -a 256 ~/Downloads/Ferry-0.1.0.dmg
```

输出的一长串字符和 `.sha256` 文件里的一致，就说明文件完整、没有被改过。

## 可以做什么

- **连上手机**：插上数据线后，一步步告诉你手机上要点哪里（解锁、把 USB 用途改成“传输文件”）。手机被别的程序占用时，直接说出是哪个程序。
- **导入照片和视频**：按拍摄日期分组，默认只选上次导入后新拍的；改过名、换过文件夹的照片也不会重复导入。
- **浏览手机文件**：大文件夹也不用等；按空格直接预览照片和视频。
- **两边拷贝**：和访达之间拖拽，或者 ⌘C / ⌘V。
- **不怕断线**：拔线、锁屏、退出 App 后，没传完的会从断点继续。
- **删除可以反悔**：从手机删除时默认先在 Mac 上留一份备份，可以放回手机。

每个版本改了什么，见[更新记录](CHANGELOG.md)。

## 隐私

- Ferry **不联网**，不需要账号，不收集任何数据。文件只在你的手机和这台 Mac 之间传输。
- 诊断日志只保存在你的 Mac 上（“应用程序支持/Ferry/Logs”），不记录文件名、路径和文件内容。
- 连不上手机时，可以用“帮助 › 导出诊断信息…”存下一个文本文件，自己决定要不要发给我们。里面有 Mac 和手机的型号、连接情况和出错记录，手机序列号只保留最后 4 位。

## 反馈问题

- 使用中的问题和建议：在 [Issues](https://github.com/reatang/ferry-android-file-release/issues) 里提出，最好附上“帮助 › 导出诊断信息…”生成的文件。
- **安全问题请不要公开发 Issue**，通过 [私密漏洞报告](https://github.com/reatang/ferry-android-file-release/security/advisories/new) 告诉我们，我们会尽快回复并修复。
